# Audio Files

## North Star AI Theme

Add your audio file here:

**Filename:** `north-star-theme.mp3`

The audio player on the website looks for `audio/north-star-theme.mp3`. 

### How to add your audio:

1. Place your MP3 file in this directory and name it `north-star-theme.mp3`
2. The player will automatically load and play it
3. Supported formats: MP3, WAV, OGG, M4A

### Audio Requirements:

- Format: MP3 (recommended for browser compatibility)
- Location: `audio/north-star-theme.mp3`
- File size: Keep under 10MB for optimal loading

Once you add the file, the audio player will be fully functional!
